# Изменения

## 0.1.2, 2026-11-12

- `CLAUDE.md` со ссылкой на `AGENTS.md`: правила агента подхватываются в
  Claude Code.
- `.claude/settings.json`: хук `Stop` с напоминанием о памяти, как в конфиге
  ZCode.
- Пример в README и `tools/init_project.py` на нейтральном имени
  «Интеграция с кассой».
- README: сценарий «попросите агента» - наложение шаблона на папку проекта
  готовым текстом просьбы, без ручной работы с командной строкой.
- `tools/init_project.py`: если папка проекта ещё не внутри репозитория git,
  скрипт выполняет `git init` с веткой `main`.
- `setup/README.md`: что делать, если хуки не срабатывают из-за заглушки
  Microsoft Store вместо `python`.

## 0.1.1, 2026-11-11

- Навык спецификации назван так, как его создаёт OpenSpec: `openspec-propose`.
- `setup/README.md`: шаг `openspec init --tools <клиент>`, который кладёт навыки
  OpenSpec в проект.

## 0.1.0, 2026-11-11

Первая версия шаблона:

- правила агента `AGENTS.md` с местами под проект;
- wiki с правилами записи, ответа и проверки (`wiki/AGENTS.md`), индексом и
  журналом;
- сырьё задач `docs/research/` и записи решений `docs/adr/` с правилами;
- память проекта `memory/` и хуки памяти `tools/hooks/` для ZCode и Claude Code;
- каркас OpenSpec, папки пакетов `deliverables/` и кода `src/`;
- подключение code-index для ZCode (`.zcode/config.json`) и Claude Code
  (`.mcp.json`);
- скрипт `tools/init_project.py`: заполнение шаблона и наложение на
  существующий репозиторий.
