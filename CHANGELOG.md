# Изменения

## 0.1.0, 2026-11-11

Первая версия шаблона:

- правила агента `AGENTS.md` с местами под проект;
- wiki с правилами записи, ответа и проверки (`wiki/AGENTS.md`), индексом и
  журналом;
- сырьё задач `docs/research/` и записи решений `docs/adr/` с правилами;
- память проекта `memory/` и хуки памяти `tools/hooks/` для ZCode и Claude Code;
- каркас OpenSpec, папки пакетов `deliverables/` и кода `src/`;
- подключение code-index для ZCode (`.zcode/config.json`) и Claude Code
  (`.mcp.json`);
- скрипт `tools/init_project.py`: заполнение шаблона и наложение на
  существующий репозиторий.
