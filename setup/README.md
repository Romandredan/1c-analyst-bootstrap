# Рабочее место проекта

## Инструменты

Рабочее место ставит и проверяет навык `analyst-workplace-setup`. Попросите
агента: «Подготовь рабочее место аналитика, ступень 2» (или 3 для контура 1С).
После установки навык записывает фактические версии в `setup/versions.md`.

## Навыки OpenSpec

Навыки спецификации (`openspec-propose`, `openspec-apply-change` и другие)
OpenSpec кладёт в сам проект. В корне проекта:

```powershell
openspec init --tools zcode
```

Для Claude Code `--tools claude`, для нескольких клиентов список через запятую.
Команда добавляет `.zcode/skills/` и `.zcode/commands/` (или `.claude/...`) и не
меняет `openspec/config.yaml` и `.zcode/config.json`. Сгенерированные файлы
фиксируются в git вместе с проектом, чтобы у всей команды была одна версия.

## Разделы wiki

Знания «как устроено» копятся в `wiki/`. Разделы (4–7 по главным предметам
системы, например «Оплата и фискализация», «Интеграции», «Склад») называет
владелец проекта:

1. Замените в `wiki/index.md` заголовки-заглушки разделов на свои
   (незаполненные места init-скрипт перечисляет в «Осталось заполнить»).
2. Создайте папки `wiki/<раздел>/`.

Разделы не заданы сразу — не блокируют работу: при первом знании «как
устроено» агент предложит список разделов и после подтверждения создаст
папки и первую страницу одним действием (правила `wiki/AGENTS.md`).

## Индекс кода

1. Выгрузите конфигурацию в XML в `src/cf/`.
2. Добавьте путь в настройки индекса `bsl-indexer` (`daemon.toml`) с алиасом
   `<АЛИАС_КОДА>` и перезапустите службу индекса.
3. Проверьте: агент находит известный объект конфигурации через `code-index`.

## Подключение MCP и хуков

| Клиент агента | MCP | Хуки памяти и wiki |
|---|---|---|
| ZCode | `.zcode/config.json` | `.zcode/config.json` |
| Claude Code | `.mcp.json` | `.claude/settings.json` |

При первом открытии проекта клиент спросит, доверять ли MCP-серверам проекта.
Доверие хранится по пути к папке: после переноса проекта на другой компьютер
или в другую папку подтверждение понадобится снова. ZCode отдельно спрашивает
доверие к проектным хукам, и любая правка `.zcode/config.json` меняет digest
конфигурации — доверие будет запрошено заново.

Шлюз `odata1c` подключается не здесь, а на уровне клиента: он один на все
проекты.

Если хуки не срабатывают, проверьте команду `python --version` в терминале
клиента: когда Python не установлен, Windows подставляет заглушку Microsoft
Store, которая вместо запуска открывает магазин. В этом случае в
`.zcode/config.json` и `.claude/settings.json` замените `python` на полный
путь к установленному интерпретатору (например,
`C:/Users/<имя>/AppData/Local/Programs/Python/Python312/python.exe`).
