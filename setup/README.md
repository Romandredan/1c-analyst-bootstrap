# Рабочее место проекта

## Инструменты

Рабочее место ставит и проверяет навык `analyst-workplace-setup`. Попросите
агента: «Подготовь рабочее место аналитика, ступень 2» (или 3 для контура 1С).
После установки навык записывает фактические версии в `setup/versions.md`.

## Индекс кода

1. Выгрузите конфигурацию в XML в `src/cf/`.
2. Добавьте путь в настройки индекса `bsl-indexer` (`daemon.toml`) с алиасом
   `<АЛИАС_КОДА>` и перезапустите службу индекса.
3. Проверьте: агент находит известный объект конфигурации через `code-index`.

## Подключение MCP и хуков

| Клиент агента | MCP | Хуки памяти |
|---|---|---|
| ZCode | `.zcode/config.json` | `.zcode/config.json` |
| Claude Code | `.mcp.json` | `.claude/settings.json` |

При первом открытии проекта клиент спросит, доверять ли MCP-серверам проекта.
Доверие хранится по пути к папке: после переноса проекта на другой компьютер
или в другую папку подтверждение понадобится снова.

Шлюз `odata1c` подключается не здесь, а на уровне клиента: он один на все
проекты.
