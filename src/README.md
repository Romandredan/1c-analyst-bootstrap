# Код конфигурации

Выгрузка конфигурации 1С в XML и код расширений, обработок и отчётов:

| Папка | Что лежит |
|---|---|
| `cf/` | Конфигурация |
| `cfe/` | Расширения |
| `epf/`, `erf/` | Внешние обработки и отчёты |
| `tests/` | Тесты |

Агент читает код только через индекс `code-index`: файлы выгрузки слишком
велики, чтобы читать их целиком. Индекс строится по этой папке, алиас задаётся
в настройках индекса на машине (`setup/README.md`).

Если проект общий с командой разработки, папка совпадает с её `src/`, и правка
аналитика уходит на ревью разработчику. Если проект только аналитический,
выгрузка конфигурации в git не хранится: строка `src/cf/` в `.gitignore`.
