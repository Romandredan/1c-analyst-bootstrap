# Память проекта

Здесь агент записывает, как работать в этом проекте. Знание о системе и процессе
сюда не пишется: оно живёт в `wiki/`. Решения живут в `docs/adr/`.

| Папка | Что записывается | Пример |
|---|---|---|
| `agreements/` | Договорённости с заказчиком и владельцами рисков о том, как вести работу | Кто принимает решение по чекам; что заказчик не хочет видеть в решениях |
| `lessons/` | Уроки: где агент ошибся или чуть не ошибся, и правило, которое это предотвращает | Слова участника встречи записаны как факт |

Одна запись: один файл `<папка>/<короткое-имя>.md` с шапкой:

```
---
description: одна строка, по которой агент решает, читать ли запись
source: файл и место, откуда взята договорённость или урок
date: ГГГГ-ММ-ДД
---
```

Под шапкой: суть в одном-двух предложениях, затем «Как применять».

Оглавление памяти показывает агенту хук на старте каждой сессии
(`tools/hooks/memory_index.py`), напоминание записать новое приходит в конце
работы (`tools/hooks/memory_reminder.py`).
