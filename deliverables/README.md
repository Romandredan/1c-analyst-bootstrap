# Пакеты аналитика

Пакеты собирает навык `analyst-handoff`. Один кейс: одна папка.

```text
deliverables/<кейс>/
├── customer/   # пакет на согласование: package.md, диаграммы, экраны, build/ с DOCX и HTML
└── dev/        # пакет для разработки: карта, трассировка, границы и риски
```

Текст пакета для заказчика живёт в одном файле `customer/package.md`: диаграммы,
экраны и сборка строятся из него. Правки заказчика вносятся туда же, версия
растёт, изменения записываются в `customer/CHANGELOG.md`.
