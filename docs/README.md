# Документы проекта

| Папка | Что лежит | Кто пишет |
|---|---|---|
| `research/` | Сырьё задач: письма, транскрипты встреч, ответы заказчика, результаты разбора | Внешний мир и навыки разбора; сырьё не переписывается |
| `adr/` | Записи решений (ADR, Architecture Decision Record) | Аналитик с агентом, подтверждает владелец решения |

Знания о системе живут в `wiki/`, спецификации изменений в `openspec/`, пакеты
для заказчика и разработки в `deliverables/`.
