# Сырьё задач

Одна задача: одна папка `research/<кейс>/`. Внутри файлы с номером по порядку
появления, например:

```text
research/<кейс>/
├── 01-письмо.md
├── 02-встреча-1-транскрипт.md
├── 03-извлечение-требований.md
└── 04-ответы-заказчика.md
```

Правила:

- Сырьё не правится. Уточнение или исправление ложится новым файлом со ссылкой
  на исходный.
- Перед тем как положить транскрипт, уберите из него то, что не должно попасть в
  репозиторий и в облачную модель: персональные данные, названия контрагентов,
  коммерческие условия. Правила замены храните рядом, в `research/<кейс>/`.
- Результат разбора (извлечение требований, брейншторм) лежит рядом с сырьём,
  выводы из него переносятся в `wiki/` и `docs/adr/`.
