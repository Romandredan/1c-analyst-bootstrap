# Записи решений (ADR)

ADR фиксирует решение, которое дорого отменить: что решили, какие варианты
рассматривали и чем за это платим. Формат записи: навык `domain-modeling`.

- Имя файла: `NNNN-<коротко-о-решении>.md`, нумерация сквозная, без подпапок.
- Статусы: `proposed` (предложено), `accepted` (подтверждено владельцем),
  `superseded` (заменено, со ссылкой на новую запись).
- `accepted` ставится только после явного подтверждения владельца решения,
  например подписи пакета на согласование.
- Принятая запись не переписывается. Решение изменилось: новая запись, старая
  получает статус `superseded`.
- Утверждение без проверенного источника помечается `[ПРОВЕРЬ: чем проверить]`.
